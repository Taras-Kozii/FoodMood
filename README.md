FoodMood — a modern responsive landing page for a digital menu and online food ordering service for restaurants and cafes. The project is focused on product presentation, customer engagement, and showcasing platform functionality through modern UI/UX design, smooth animations, and well-structured content. The landing page was created with an emphasis on readability and visual appeal.

## 🔗 Live Demo

[FoodMood](https://taras-kozii.github.io/FoodMood/)

## 🚀 Core Technologies

- HTML5 — semantic page structure
- CSS3 — styling, responsive layout, and UI animations
- JavaScript (Vanilla JS) — interactivity and interface behavior
- Responsive Web Design (RWD) — adaptation for mobile/tablet/desktop
- Flexbox & CSS Grid — building a modern layout system
- CSS Transitions & Animations — smooth hover effects and transitions
- Git & GitHub Pages — version control and project deployment
